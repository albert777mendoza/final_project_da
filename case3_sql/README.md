# Caso 3 – SQL

## Español
### Objetivo
Analizar una base de datos relacional sobre libros, editoriales, autores y calificaciones de clientes para generar una propuesta de valor enfocada en un nuevo producto.

### Hallazgos Clave
- Se identificaron **819 libros publicados después del 2000**, reflejando una base representativa de producción editorial reciente.  
- La calificación promedio de los libros muestra alta variabilidad: algunos alcanzan 5.0, mientras otros apenas 1.5.  
- **Penguin Books y Vintage** dominan la producción editorial, evidenciando concentración en pocos actores.  
- El autor con mayor promedio de calificación fue **J.K. Rowling/Mary GrandPré (4.28)**, confirmando la influencia de autores reconocidos.  
- Los usuarios más activos (más de 50 libros calificados) escriben en promedio **24 reseñas**, lo que muestra que la creación de contenido requiere mayor compromiso.  

### Conclusión y Recomendaciones
- Fomentar la creación de reseñas mediante incentivos (gamificación, reconocimientos).  
- Promover la diversidad editorial con recomendaciones personalizadas y secciones de descubrimiento.  
- Implementar filtros y segmentaciones para gestionar la variabilidad en la percepción de calidad.  
- Capitalizar la influencia de autores reconocidos para atraer lectores, mientras se visibilizan autores menos conocidos.

## English
### Objective
Analyze a relational database on books, publishers, authors, and customer ratings to generate a value proposition for a new product.

### Key Findings
- Identified **819 books published after 2000**, representing recent editorial production.  
- Average ratings show high variability: some books scored 5.0, others as low as 1.5.  
- **Penguin Books and Vintage** dominate publishing, reflecting market concentration.  
- The author with the highest average rating was **J.K. Rowling/Mary GrandPré (4.28)**, highlighting the influence of renowned authors.  
- Highly active users (rated more than 50 books) wrote on average **24 reviews**, showing that written content requires greater commitment.  

### Conclusion and Recommendations
- Encourage review creation through incentives (gamification, recognition).  
- Promote editorial diversity with personalized recommendations and discovery sections.  
- Implement filters and segmentation to manage variability in perceived quality.  
- Leverage the influence of renowned authors to attract readers while highlighting lesser-known ones.
