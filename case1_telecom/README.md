Caso 1 – Análisis de Telecomunicaciones
Español
Objetivo
Identificar operadores ineficaces del servicio de telefonía virtual CallMeMaybe mediante análisis exploratorio y métricas de eficiencia.

Hallazgos Clave
Las llamadas salientes presentan mayor tasa de pérdida (52.56%) que las entrantes (41.46%).
La mediana de duración de llamadas salientes es 0 minutos, reflejando ineficiencia estructural.
Las llamadas internas muestran mayor tasa de pérdida incluso con operador (45.49%).
El sistema automático sin operador no es viable: ≈99% de llamadas perdidas.
Estrategias Recomendadas
Optimizar bases de datos y horarios de contacto.
Implementar dashboards de monitoreo.
Fortalecer procesos de capacitación y gestión de tiempos.
Rediseñar procesos internos y mejorar el sistema automático.

English
Objective
Identify inefficient operators of the virtual telephony service CallMeMaybe through exploratory analysis and efficiency metrics.

Key Findings
Outgoing calls show a higher drop rate (52.56%) than incoming calls (41.46%).
Median duration of outgoing calls is 0 minutes, indicating structural inefficiency.
Internal calls have the highest drop rate even with operators (45.49%).
Automated system without operators is not viable: ≈99% of calls lost.
Recommended Strategies
Optimize databases and contact schedules.
Implement monitoring dashboards.
Strengthen training and call time management.
Redesign internal processes and improve the automated system.
